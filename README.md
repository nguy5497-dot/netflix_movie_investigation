# netflix_movie_investigation

## Project Objective

In this project, I wanted to discover trends among movies made in the 1990's. I recently started to learn how to use pandas and matplotlib so this project is simple. I wanted to emphasize my use of visualization, specifically histograms, to highlight the importance of how visuals allow for easy interpretation.

### Methods Used
- Data Analysis
- Data Visualization

### Technologies

- Python
- Pandas
- MatPlotLib

### Project Description

Starting off, I created a dataframe based off of 'netflix_data.csv'. I then filtered the dataframe to only movies made between 1990-1999. I felt like the data I wanted to represent is best shown through histograms. Using Pandas, I filtered the sub-dataframe (1990's) catered to my three discoveries: Most frequent movie duration in the 1990's, The most common movie genre in the 1990's, The country that produced the most Action movies in the 1990's.

Here were my discoveries:

- Most frequent movie duration in the 1990's: About 92 minutes

- The most common movie genre in the 1990's: Action

- The country that produced the most Action movies in the 1990's: United States
